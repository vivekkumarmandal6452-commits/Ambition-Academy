# 🌟 Ambition Academy

> **Learn. Achieve. Go Beyond.**

Ambition Academy is a modern, full-stack, enterprise-grade EdTech platform designed for school education, competitive exams (JEE Main & Advanced, NEET UG, UPSC CSE), coding, and professional skill development.

---

## ⚡ Tech Stack

- **Frontend**: React 19, TypeScript, Vite, Framer Motion, Lucide Icons, CSS Custom Design System
- **Backend**: Node.js, Express, TypeScript, Supabase Auth & DB client with Disk Persistence Fallbacks
- **Security**: JWT Authentication, Role-based Access Control (Admin / Student), Helmet, CORS, Rate-limiting

---

## 🚀 Key Features

- 🎓 **Interactive Learning Hub**: Live classes, recorded video lectures, DPP practice sets, full-length test series, chapterwise study materials & notes.
- 💳 **Seamless Enrollment Flow**:
  - Free Courses (`price === 0`): Instant 1-click enrollment.
  - Paid Courses (`price > 0`): PW-style Checkout & Payment Gateway modal with UPI, QR code, Card, and Net Banking options.
- 👑 **Master Admin Control Hub**: Full control over course creation, video uploads, DPP scheduling, live class links, user management, and gallery photo uploads.
- 🖼️ **Campus & Event Gallery**: Public and student gallery showcasing rankers, live interactive sessions, and campus events.
- 📜 **Official Printable Certificates**: Automatically generated verified completion certificates for students.
